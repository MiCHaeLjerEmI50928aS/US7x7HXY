# Learner Guide - Pearson Vue Certified IT Specialist Cloud Computing

## Course Overview

This learner guide supports **TGS-2025056362 - Pearson Vue Certified IT Specialist - Cloud Computing**. The course uses a practical case study called **Contoso Cloud Migration**, where learners plan how to move a small training registration application from an on-premises environment to the cloud.

The labs align to foundational cloud computing skills expected of entry-level IT certification learners: cloud concepts, deployment and service models, compute, storage, networking, security, cost, governance, monitoring, availability, and migration planning.

## Prerequisites

Learners should have:

- Basic computer and internet literacy.
- Basic understanding of servers, files, users, and networks.
- Basic spreadsheet or table-reading skills.
- A laptop with internet access.

No prior cloud provider experience is required.

## Learning Outcomes

By the end of this course, you will be able to:

1. Define cloud computing and common cloud benefits.
2. Compare cloud service models and deployment models.
3. Explain the shared responsibility model.
4. Choose compute, storage, database, and networking options for a simple workload.
5. Apply basic identity and access management controls.
6. Create basic security, backup, and monitoring plans.
7. Estimate and control cloud costs.
8. Document a simple cloud migration plan.
9. Explain high availability, disaster recovery, and operational monitoring.
10. Review certification readiness across foundational cloud topics.

## Case Study: Contoso Cloud Migration

Contoso runs a small training registration application with:

- A public website.
- An application server.
- A relational database.
- Uploaded course brochures and images.
- Admin users and learner users.
- Daily backups.
- Email notifications.

Contoso wants cloud benefits such as faster scaling, improved availability, managed services, clearer backup processes, and better monitoring.

## Safety and Cost Rules

- Do not create paid resources unless instructed.
- Delete any test resources you create.
- Do not share cloud credentials.
- Enable MFA on any account used for practice.
- Keep screenshots free of account IDs, keys, and secrets.

## Certification Study Tips

- Know IaaS, PaaS, SaaS, public, private, hybrid, and multi-cloud.
- Understand shared responsibility.
- Compare compute options such as virtual machines, containers, and serverless.
- Know basic storage types: object, block, file, archive, and database storage.
- Understand IAM, least privilege, MFA, encryption, and secrets.
- Be able to explain monitoring, scaling, backups, availability, and disaster recovery.
